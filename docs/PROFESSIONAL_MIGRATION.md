# Professional Squarespace → Astro migration

`squarespace-to-astro` remains free and open source under the MIT licence. The professional service is optional: you are paying for a bounded migration, QA, and handoff rather than for access to the software.

## Fixed simple-site offer

**US$1,500 fixed price** for one customer-owned public brochure/content Squarespace site that fits the scope below.

Included:

- source-site migration using the public crawl and/or a customer-provided Squarespace WordPress XML export;
- supported asset download and localisation;
- editable Astro project generation;
- redirect mapping for agreed legacy routes;
- one staging build;
- bounded QA and documented known deviations;
- source-project and handoff notes.

The source Squarespace site should remain live until customer-approved cutover.

## Not included in the fixed offer

- commerce or checkout data;
- events;
- form submissions or historical form data;
- member systems or members-only functionality;
- Squarespace administration settings;
- bespoke application features;
- substantial redesign or complex manual layout reconstruction;
- automated interactive two-factor authentication;
- SEO-ranking guarantees, exact pixel identity, or zero-downtime guarantees.

If these appear during intake or migration, the project stops for re-scoping before additional work is performed.

## Acceptance criteria

The fixed-scope migration is complete when:

1. the agreed page/content set is represented in an editable Astro project;
2. in-scope assets resolve locally or an intentional external reference is documented;
3. redirects cover the agreed legacy routes;
4. the staging project builds successfully;
5. known deviations are documented; and
6. the customer receives the source project and handoff notes.

## Before work starts

The customer must confirm ownership or authorisation for the source site, provide the source URL and any agreed export/access material, confirm the fixed scope and exclusions, and pay the agreed deposit before project-specific work begins.

## Enquiries

Open a GitHub issue in this repository titled **Migration service inquiry** with a brief description of the public site, approximate page count, whether it has a blog, and any known commerce/forms/membership features. Do **not** include credentials, private exports, cookies, session data, API keys, or other secrets in a public issue. Private access material is requested only after scope and engagement are agreed.
