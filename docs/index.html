Squarespace Migration Tooling

squarespace-to-astro (s2a)

A Python CLI that probes and crawls Squarespace sites, captures authenticated content, imports WordPress XML exports, and generates buildable Astro projects.

GitHub Repo Releases Astro Repo

What it does

Capture the source site

Probe sitemap and robots behavior, crawl pages, store HTML and JSON snapshots, and preserve browser-authenticated access with Playwright storage state.

Normalize migration inputs

Merge Squarespace WordPress XML exports into the snapshot so page and post content can be resolved from the strongest available source.

Generate a static target

Produce a developer-editable Astro project with Markdown content, route data, navigation, and generation metadata.

Keep runs inspectable

Default CLI runs create unique folders under site-output/ and write execution-metadata.json for repeatable debugging and auditing.

Install and run

Homebrew install is available on macOS arm64 and Linux x86_64: 

brew tap krahd/tap
brew install s2a

For local development in a repository clone, use the editable install path: 

python -m venv .venv
source .venv/bin/activate
pip install -e .[dev]
python -m playwright install chromium

export SQUARESPACE_USER=owner@example.com
export SQUARESPACE_PWD=owner-password

s2a migrate https://example.squarespace.com \
  --xml-export ./exports/squarespace-wordpress.xml

The generated site is a normal Astro project. After generation, move into the output directory and run npm install followed by npm run dev.

Outputs

Snapshot artifacts

  • probe.json
  • site_snapshot.json
  • report.json
  • raw-html/ and raw-json/
  • execution-metadata.json

Generated project

  • migration-manifest.json
  • src/content/pages/*.md
  • src/content/posts/*.md
  • src/data/site.json
  • src/layouts/ and src/pages/

Current boundaries

  • 2FA is not supported in the automated browser-auth flow.
  • Utility routes such as /cart, /checkout, and /account are intentionally skipped.
  • Commerce, events, forms, members, and full admin automation are not migrated.
  • Asset downloading and redirect generation are still pending.
